# ตัวชี้วัดคุณภาพการพยาบาลวิสัญญี (QI) — ส่วนเสริมของ P4P Anes

หน้าโฮมของแอป P4P มีปุ่มที่ 3 **"ตัวชี้วัดคุณภาพ (QI)"** มี 4 แท็บ

| แท็บ | ใครใช้ | ทำอะไร |
|---|---|---|
| บันทึก Event | วิสัญญีพยาบาลทุกคน | บันทึก**เฉพาะเคสที่มีเหตุการณ์** เลือกได้หลาย Event ในครั้งเดียว |
| ประวัติ | ผู้บันทึก | ดู/ลบ Event ที่บันทึกจากเครื่องนี้ 7 วันล่าสุด |
| Dashboard | ทุกคน | ตัวชี้วัดสะสมรายเดือน + กราฟรายวัน + แนวโน้ม 12 เดือน |
| Admin 🔒 | ผู้รับผิดชอบ (ใส่ PIN) | กรอกยอดผู้ป่วยรายวันจากรายงาน HosXP (ตัวหาร) + ติ๊ก "ตรวจสอบแล้ว" |

อ้างอิงนิยามและสูตร: กองการพยาบาล สป.สธ. ชุดหนังสือมาตรฐานฯ เล่มที่ 9 (2568) บทที่ 2 ส่วนที่ 4

## ตัวชี้วัด 14 ตัวที่เก็บผ่านแอป

| ตัวชี้วัด | A (ตัวตั้ง) | B (ตัวหาร) |
|---|---|---|
| 2.2 เลื่อนผ่าตัด: ผู้ป่วยไม่พร้อม | Event | ยอดผู้ป่วย (Admin) + เคสที่เลื่อน |
| 2.3 เลื่อนผ่าตัด: ยา/อุปกรณ์ไม่พร้อม | Event | ยอดผู้ป่วย (Admin) + เคสที่เลื่อน |
| 5.6 ไม่พร้อมช่วยชีวิตฉุกเฉิน | Event (นับจำนวน) | — |
| 5.7 ยาเสพติดประเภท 2 | Event (นับจำนวน) | — |
| 6.1 แก้ไขภาวะคุกคามชีวิตภายใน 4 นาที | CPR ที่เริ่มภายใน 4 นาที (ระบบคำนวณจากเวลา) | Event CPR ทั้งหมด |
| 6.2 Unplanned ICU / Unexpected death | Event | ยอดผู้ป่วย (Admin) |
| 6.3 ภาวะแทรกซ้อนที่ป้องกันได้ | Event | ยอดผู้ป่วย (Admin) |
| 6.4 Re-intubation ใน PACU | Event | ยอดใส่ ETT (Admin) |
| 6.5 อุบัติการณ์ระหว่างเคลื่อนย้าย | Event | ยอดผู้ป่วย (Admin) |
| 6.6 Med error ระดับ E–I | Event ระดับ E–I | Med error ทั้งหมด (A–I) |
| 6.7 ความคลาดเคลื่อนการให้เลือด ระดับ E–I | Event ระดับ E–I | ทั้งหมด (A–I) |
| 6.8 ระบุตัวผู้ป่วยผิดคน | Event (นับจำนวน) | — |
| 6.9 พลัดตกหกล้ม ระดับ E–I | Event ระดับ E–I | ทั้งหมด (A–I) |
| 6.10 บาดเจ็บจากจัดท่า/ผูกยึด/อุปกรณ์ | Event | ยอดผู้ป่วย (Admin) |

ตัวชี้วัดด้านบริหาร (มิติ 1, 3, 4, มิติ 5 ข้อ 1–5, ข้อ 2.1, 2.4, 2.5) ไม่ได้เก็บผ่านแอปนี้

## กติกาที่ต้องสื่อสารกับทีม

1. **วันที่ของ Event = วันที่เริ่มให้ยาระงับความรู้สึก** (เคสคร่อมเวร/คร่อมวัน) เพื่อให้ตรงกับยอดผู้ป่วยจาก HosXP
2. **Med error / การให้เลือด / พลัดตกหกล้ม รายงานทุกระดับ A–I รวม near miss** ไม่เช่นนั้นผลจะเป็น 100% ทุกครั้ง
3. **6.5 และ 6.10 ใช้ยอดผู้ป่วยทั้งหมดเป็นตัวหาร** (นิยามเชิงปฏิบัติการของหน่วยงาน: ผู้ป่วยทุกรายมีการเคลื่อนย้ายและจัดท่า)
4. ถ้า HN + วันที่ มี Event อยู่แล้ว แอปจะเตือน ถ้าเป็นเหตุการณ์เดียวกัน (เช่น ส่งต่อเวร) ไม่ต้องบันทึกซ้ำ
5. ยอดผู้ป่วยต้อง**นับไม่ซ้ำคน** (จาก HosXP) ห้ามใช้ยอด P4P ซึ่งนับซ้ำตามเวร

## ติดตั้งฝั่งเซิร์ฟเวอร์ (ทำครั้งเดียว ~10 นาที)

ใช้ Apps Script **แยกจาก P4P** — ไม่ต้องแก้ `Code.gs` เดิม และข้อมูล HN ผู้ป่วยแยกอยู่คนละไฟล์ (จำกัดสิทธิ์ได้ง่ายกว่า ตาม PDPA)

1. สร้าง Google Sheet ไฟล์ใหม่ ตั้งชื่อเช่น `QI Anes MNST` (แนะนำใช้บัญชีองค์กร และ**แชร์เฉพาะผู้รับผิดชอบ**)
2. Extensions › Apps Script → ลบโค้ดเดิม วางโค้ดทั้งหมดจาก `QI_Code.gs` → บันทึก
3. ตั้ง PIN ของหน้า Admin: Project Settings (รูปเฟือง) › Script properties › Add › Property = `ADMIN_PIN`, Value = PIN ที่ต้องการ
   (ถ้าไม่ตั้ง PIN เริ่มต้นคือ `2468` — **ควรเปลี่ยนก่อนใช้งานจริง**)
4. เลือกฟังก์ชัน `setupQiTriggers` จากดรอปดาวน์ข้างปุ่ม Run → กด Run → Authorize
   (ระบบจะสร้างชีต `QI_Events`, `QI_Daily`, `QI_Monthly` และตั้งให้สรุปรายเดือนทุกวัน 19:30 น.)
5. Deploy › New deployment › Web app → Execute as: **Me** → Who has access: **Anyone** → Deploy → คัดลอก URL ที่ลงท้ายด้วย `/exec`
6. เปิด `index.html` ค้นหา `const DEFAULT_QI_URL = "";` แล้ววาง URL ลงในเครื่องหมายคำพูด → commit ขึ้น GitHub
   (ทุกเครื่องจะใช้ได้ทันทีโดยไม่ต้องตั้งค่าทีละเครื่อง — หรือจะวางในเมนู ⚙ › "Web App URL ตัวชี้วัดคุณภาพ (QI)" ทีละเครื่องก็ได้)

> แก้โค้ด `QI_Code.gs` ภายหลัง ต้อง Deploy › Manage deployments › แก้ไข › Version: **New version** เพื่อให้ URL เดิมใช้โค้ดใหม่

## ชีตข้อมูล

- `QI_Events` — 1 แถว = 1 Event · ลบในแอปจะเปลี่ยนสถานะเป็น `deleted` (ไม่ลบแถวจริง เก็บเป็นหลักฐาน) · กันข้อมูลซ้ำด้วย EventID
- `QI_Daily` — 1 แถว = 1 วัน · บันทึกซ้ำวันเดิมจะแก้ไขทับ (ข้อมูลเก่าจากการส่งซ้ำจะไม่ทับข้อมูลใหม่กว่า)
- `QI_Monthly` — A / B / ผลลัพธ์ / ผ่าน-ไม่ผ่าน ของ 14 ตัวชี้วัด × 12 เดือน · ต่อ Looker Studio หรือคัดลอกไปรายงานได้ทันที
  (รีเฟรชเองได้ที่เมนู **QI Anes › สรุปรายเดือน** ในไฟล์ชีต)

## เมื่อได้รายงานรายวันจาก HosXP

ตอนนี้ Admin กรอกตัวเลข 2 ช่อง (ยอดผู้ป่วยรวม, ยอดใส่ ETT) ต่อวัน ถ้าไฟล์ export จาก HosXP มีรูปแบบคงที่ ส่งตัวอย่างไฟล์มา จะเพิ่มปุ่มนำเข้าไฟล์ให้กรอกทั้งเดือนในครั้งเดียวได้
